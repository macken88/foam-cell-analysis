実装マップ

画面上の機能がどのバックエンドで処理されるかを示します。hybridでは学習をTrainingService、比較・評価とリリースをComparisonServiceに委譲します。学習用・検証用データ版の読み込みはDatasetStoreを使い、取り込み・版登録などの編集操作と本番推論はMockBackendの模擬処理です。

外部解析の分担

external_analysis.pyは外部解析値の形式判定、入力値検証、全体・分類別の集計を担当します。依存はmathとtyping.Anyだけで、ファイル保存は行いません。

ComparisonServiceは候補・評価ID・固定検証版との整合を確認し、検証済み値と集計を外部解析記録へ保存します。保存形式と検証内容は比較設計 9.4節を参照してください。

各テスト欄は関連機能の代表例です。画面モックの確認にはGUI画面設計も参照してください。

計測メモ（小規模 CSV fixture）

2026-10-06 の一時計測では、get_image / get_mask を各20回行い、metadata 20 reads・manifest 40 reads、所要時間はそれぞれ 9.14 ms / 7.95 ms だった。小規模データでの観測値であり、一般的な性能保証ではない。今回、永続 cache や CSV 全体の読み込み構造は変更しない。
