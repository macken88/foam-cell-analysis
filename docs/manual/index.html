利用者マニュアル

データ準備から学習、モデル評価、リリース、本番推論までの画面操作を説明します。

章を選ぶ

  • 起動と画面の見方
  • データ準備
  • 学習設定・キュー・実験
  • 候補の評価・比較・リリース
  • 本番推論画面
  • 異常終了後の復旧
  • 困ったとき
実接続と模擬表示について
機能現在の処理
学習・評価・リリース・分類へのモデル割り当て実データを使って実行し、結果や状態を保存します。
確定済みの学習用版・検証用版の読込み保存されたデータを読み込みます。
データ準備画面での取り込み・編集・版登録模擬処理です。ここで作った版は学習に使えません。
本番推論模擬画像を表示します。実モデルによる推論と結果ファイルの保存は未対応です。

操作の流れ

データ準備 → モデル学習 → モデル比較・リリース → 本番推論

実データを使う場合は、あらかじめ用意された確定済みデータセット版を使います。データ準備画面で新たに取り込んだデータは、現在の実接続学習へ渡りません。

起動に必要な準備

アプリのインストールや起動コマンド、試用データの生成手順はREADMEを参照してください。学習を試す場合は、管理者が用意したデータセット版を使います。
