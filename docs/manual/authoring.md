## 画面撮影

再現スクリプト: `docs/manual/tools/capture_screenshots.py`。リポジトリのルートからPowerShellで次のように実行する。

```powershell
$env:QT_QPA_PLATFORM = "windows"
$env:PYTHONPATH = "src"
.venv/Scripts/python.exe docs/manual/tools/capture_screenshots.py
```

`QT_QPA_PLATFORM` はWindowsの通常描画を使い、`PYTHONPATH` は作業ツリー内のアプリを読み込むために指定する。スクリプトは `APPDATA`、設定ファイル、ショートカット表をOS一時ディレクトリへ分離する。ユーザー設定やworkspaceを読み書きしない。画面には `MockBackend` のデモ状態を表示する。

Windowsの通常Qtプラットフォームで撮影した。QSSテーマを適用し、ホームの工程パネルと各モードのタブをマウスクリックして移動した。モード画面の初期化後に `WA_DontShowOnScreen` を設定し、画面全体を `grab()` で保存した。撮影時のウィンドウは1320×860。`APPDATA`、設定ファイル、ショートカット表は一時ディレクトリへ分離し、デモ状態はメモリ内だけで扱った。キュー画面には実際の「キューに追加」操作で設定を2件登録したが、学習は開始していない。実学習・実評価は開始していない。

画像はすべて `assets/images/` 以下に置いた。タブ画面のファイル名末尾はモード内のタブ順を表し、追加のダイアログ画面は内容名を付けた。候補比較と評価詳細・抽出結果出力ダイアログは、既存デモの評価済み候補を画面上で選択して開いた。ダイアログはQTestで閉じ、実データの出力や解析値の変更は行っていない。推論は模擬の完了操作を行い、一覧の対象行を画面上で選んだ。復旧画面はデモ実験の読み取り可能な復旧状態と理由をメモリ内だけに設定し、GUIが表示する詳細欄を撮影した。これらはデモ状態のため、キャプションに模擬表示と記載した。ホームの接続方式依存の表示も含め、ユーザーのworkspaceや実データは撮影に使っていない。

本番推論画面の出力先表示には、画面の参照操作で選んだ一時フォルダを使い、撮影後にスクリプトが作った出力用フォルダだけを削除する。`C:/Temp` が撮影前から存在した場合は触れず、スクリプトが新規作成した場合も中が空のときだけ削除する。アプリの設定、ショートカット、その他の撮影データはOSの一時ディレクトリに置いた。モードの全体表示が収まらない場合は、比較・リリース画面だけ高さを1040 pxにした。評価詳細と出力設定のダイアログは、内容が見えるよう1200×800 pxに広げて撮影した。
